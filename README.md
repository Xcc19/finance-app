# 🛡️ Wealth Pilot Pro | 个人资产风险监控终端

这是一个基于 Python 和 Streamlit 开发的轻量级金融风控工具，旨在帮助个人投资者从“审计与风控”视角审视资产健康度。

### ✨ 核心亮点
- **多维风控模型**：引入五维雷达图，从流动性、抗通胀、防御力等维度对资产进行性格画像。
- **实时汇率引擎**：支持 CNY/USD/JPY 自动折算与通胀损耗模拟。
- **UI 设计**：采用响应式暗黑模式（Dark Mode），集成 Plotly 高级交互式图表。

### 🚀 快速启动
1. 安装依赖：`pip install -r requirements.txt`
2. 启动终端：`streamlit run app.py`
